# Hi, I'm Sid 👋

**AI Engineer building practical AI systems and intelligent automation**

I'm someone who thinks across multiple dimensions — not just about code and models, but about *why* we're building something in the first place.

I've had chances to understand how software actually gets built, how to identify real problems worth solving, and how people use the systems we create. That perspective shapes everything I build.

I don't just build systems; I'm interested in the *variety* of ways AI can solve different problems, and how they integrate into real systems in ways that actually matter.

---

## 🧭 What I've Explored

I've had the chance to work on quite different problems, and I think that variety matters:

* **RAG Systems** — When you need AI to actually know your specific data and retrieve it reliably
* **Enterprise AI Platforms** — Understanding how LLMs fit into existing enterprise ecosystems
* **Text-to-SQL** — Making language models work with structured data
* **RPA + AI Hybrid Systems** — Combining automation with reasoning capabilities

> A clean retrieval system sometimes beats a fancy LLM setup. Sometimes you need both.

---

## 💭 How I Think About Building

**Understanding the problem matters more than understanding the solution.**

When I build, I ask:

* What's the actual need?
* What's the simplest thing that works?
* Where does complexity create value?
* What will users actually experience?

This carries over to AI systems.

Not:

> How do I use the latest model?

But:

> What does this problem actually need?
